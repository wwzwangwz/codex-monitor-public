# App Store 元数据（简体中文）

## 名称

Codex Monitor

## 副标题

跨设备任务状态监控与引导

## 宣传文本

在 iPhone 上集中查看 Mac 与 Windows 上已选择的 Codex 会话状态，并在需要时发送原生 Steer 或 Queue 引导。

## 描述

Codex Monitor 是面向个人开发工作流的跨设备会话监控工具。

扫描电脑端二维码后，可以：

- 同时连接多台 Mac 与 Windows 电脑
- 通过绿、红、蓝、黑四色灯查看运行、受阻、完成与未知状态
- 查看每个会话最近的可见工作内容
- 仅在状态灯发生变化时接收通知
- 使用 NEW 快速定位发生变化的会话
- 向指定会话发送 Steer 当前运行或 Queue 下一轮消息
- 在局域网直连与已配置的安全远程中继之间独立选择

应用不会保存完整对话历史。局域网模式下，数据直接在手机与电脑之间传输。

## 关键词

开发工具,任务监控,远程控制,状态通知,电脑监控,会话管理

## 审核说明

应用需要配套的 Codex Monitor 电脑端。审核测试账号不需要登录；请使用审核说明中提供的测试电脑二维码连接。

摄像头仅用于扫描电脑端二维码。本地网络权限用于连接同一局域网内的电脑。通知只在会话状态灯发生变化时发送。
