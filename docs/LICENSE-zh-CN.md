# AGPL-3.0-only 中文说明

本页只用于帮助理解，不替代具有法律效力的英文 [LICENSE](../LICENSE) 和 [NOTICE](../NOTICE)。发生差异时，以英文原文为准。

## 可以做什么

- 个人、学校、研究机构和公司都可以使用。
- 允许商业使用、收费部署、销售副本和提供收费服务。
- 允许复制、修改、再发布和制作衍生版本。

## 必须遵守什么

- 保留版权声明、完整 AGPL-3.0-only 许可证和 `NOTICE`。
- 修改过的文件和版本必须明确标注已经修改，不能冒充官方版本。
- 发布安装包或其他目标代码时，必须按 AGPL 要求同时提供对应完整源码。
- 通过网络向用户提供修改后的 Codex Monitor 或 Relay 时，必须向这些用户提供正在运行版本的对应源码。
- 再发布和修改版本必须继续采用 AGPL-3.0-only，不得改成闭源许可证。
- 在随附文档或“关于/法律声明”中合理显示 Codex Monitor 名称和官方项目链接。

## 不需要做什么

- 合规使用或商用不需要事先付费或单独申请许可。
- 不要求每个使用者主动联系作者；欢迎自愿告知使用场景。
- 仅在自己设备上进行、且未分发也未向网络用户提供服务的私人修改，通常不会触发发布源码义务。

## 其他说明

- 第三方依赖分别适用其自己的 MIT、Apache、BSD 或其他许可证。
- 赞助不购买技术支持、更新优先级、商标授权，也不免除 AGPL 和 `NOTICE` 义务。
- 版权所有者仍可依法为特定分发渠道或合作方另行授予附加许可；这不会撤销任何人已经按照 AGPL-3.0-only 获得的权利。
